# 隐私与数据使用说明

## 数据最小化

应用不要求真实姓名、学校、生日、联系方式或账号。可选昵称、年级、逐题回答、观察者关系和专业解读背景仍可能构成教育相关个人数据，应按敏感信息处理。

## 本地模式

未配置 Supabase 时，所有记录保存在当前浏览器的 `localStorage`。数据不会主动发送到项目服务器，但同一设备和浏览器配置下的其他使用者可能访问这些记录。清除站点数据会永久删除记录。

## 云端模式

配置 Supabase 后，浏览器会直接调用 Supabase REST API。示例迁移使用宽松匿名策略，只用于受控开发和内测；它不能证明调用者有权读取某份记录。

公开部署前至少需要：

- 学生与观察者分离的一次性、可撤销访问令牌；
- 服务端记录级授权与最小权限 RLS；
- 数据保留、下载、更正和删除流程；
- 日志脱敏、速率限制和滥用监测；
- 面向未成年人的知情同意与监护人流程；
- 明确的隐私政策、数据控制者和联系渠道。

## 导出

专业资料包可能包含学业、经历、家庭考虑和指导老师观察。用户将其复制到外部 AI 或其他服务前，应了解该服务的隐私条款，并避免包含非必要身份信息。
